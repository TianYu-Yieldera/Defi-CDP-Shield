# Voice AI Sound Files

This directory should contain the following sound files for the voice alert system:

## Required Files

1. **critical.mp3** - Emergency alert sound
   - Used when health factor drops below 1.1
   - Should be attention-grabbing and urgent
   - Recommended duration: 1-2 seconds

2. **warning.mp3** - Warning alert sound
   - Used when health factor drops below 1.3
   - Should be noticeable but less urgent than critical
   - Recommended duration: 1-2 seconds

3. **success.mp3** (optional) - Success notification sound
   - Used when operations complete successfully
   - Should be pleasant and brief
   - Recommended duration: 0.5-1 second

4. **start.mp3** (optional) - Voice recognition start sound
   - Used when user starts voice input
   - Should be subtle and brief
   - Recommended duration: 0.3-0.5 seconds

## Recommended Sources

- Free sound effects: [Freesound.org](https://freesound.org)
- Free alert sounds: [Mixkit](https://mixkit.co/free-sound-effects/alert/)

## File Format

- Format: MP3
- Sample rate: 44.1kHz
- Bit rate: 128kbps or higher
- Mono or stereo
